OmniQEC is an open research platform for discovering, evaluating, and deploying quantum error-correction stacks — from code search to syndrome circuits, decoders, and hardware execution.

Platform statusResearch preview
One QEC stack.
Every layer measurable.

Code + syndrome circuit + decoder + noise + hardware target + evaluation protocol.

From search space to executable fault-tolerant stacks.

OmniQEC treats QEC as a full-stack optimization problem. A code is not useful in isolation; the circuit, decoder, noise model, and hardware constraints determine whether it is actually good.
